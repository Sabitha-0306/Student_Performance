# 🚖 Uber Fare Prediction

## 📌 Project Overview
This project predicts the fare amount of Uber rides using Machine Learning. The dataset was cleaned, analyzed, visualized, and trained using Regression algorithms.

## 🎯 Objective
To predict the Uber fare amount based on pickup location, dropoff location, and passenger count.

## 🛠️ Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 📂 Dataset
- Uber Fare Dataset
- Target Variable: `fare_amount`

## 🔄 Project Workflow
1. Import Libraries
2. Load Dataset
3. Data Cleaning
   - Handle missing values
   - Remove duplicate records
   - Remove unwanted columns
4. Data Visualization
   - Histogram
   - Bar Plot
   - Line Plot
   - Box Plot
   - Scatter Plot
   - Correlation Matrix
   - Heatmap
5. Feature Selection
6. Train-Test Split
7. Model Building
   - Linear Regression
   - Random Forest Regressor
8. Prediction
9. Model Evaluation

## 📊 Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## 📁 Project Files
- `Uber.ipynb` – Google Colab Notebook
- `uber_cleaned.csv` – Cleaned Dataset
- `README.md` – Project Documentation

## 📌 Conclusion
This project demonstrates the complete machine learning workflow, including data preprocessing, exploratory data analysis, model training, prediction, and evaluation for a regression problem.
